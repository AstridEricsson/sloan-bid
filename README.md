# SloanBid

***This is a mockup. It does not contain all Sloan classes, and the section times, ratings, and review quotes are placeholder/sample data made up for the demo — not real reviews, real ratings, or official schedule times. Do not use this app to make actual bidding decisions.***

*The pitch deck's customer-interview quotes are real, from real MIT Sloan SFMBA students, but the initials shown are not the actual interviewees' initials — they've been changed to protect anonymity.*

A course selection and bidding assistant for MIT Sloan MBA students. Browse courses, pick the classes you want to take, prioritize your picks, and build a schedule for the bidding round. You do the choosing — the schedule is optimized automatically, and you're only prompted to deselect a course if there's a conflict.

## Why I built this

Built as a class project for 15.785 Intro to Product Management at MIT Sloan. I ran into the course-bidding process myself and felt the tools for planning a schedule and prioritizing bids could be a lot smoother — this is an MVP built to validate the idea, not a finished product.
